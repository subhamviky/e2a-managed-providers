## Configuration reference

The cloud infrastructure keys (regions, projects, tables, databases, brokers, secret stores) are e2a-adapters' (1.7.0); its cloud profiles set them.

### Managed providers — common

| Key | Environment variable | Default | Used by |
|---|---|---|---|
| llm_sdk_max_retries | LLM_SDK_MAX_RETRIES | 0 | Provider SDK retries. 0: E2A (v1.5.1+) retries model calls by error class, honouring Retry-After within the deadline, so it is the only retry authority (no double retry) |
| llm_sdk_timeout | LLM_SDK_TIMEOUT | 60.0 | ManagedLLMService — SDK HTTP timeout; the E2A deadline still bounds every call |
| fallback_model_id | LLM_FALLBACK_MODEL_ID | None | ManagedLLMService — the model a refusal is routed to: becomes E2A's model_routes [{on: [refusal], to: <id>}] when model_routes is not set (E2A 1.6.1) |
| mcp_servers | MCP_SERVERS | [] | provider MCP connector — [{name, url, token_env}] remote MCP servers the model may call |
| embedding_model_id | EMBEDDING_MODEL_ID | None | Managed embedding models — provider model / deployment id |
| embedding_dimensions | EMBEDDING_DIMENSIONS | None | Managed embedding models — output dimensions where the model supports it |
| vector_index_name | VECTOR_INDEX_NAME | 'e2a-knowledge' | Managed vector indexes — index / collection name (the tenant namespace is added) |
| rerank_model_id | RERANK_MODEL_ID | None | Managed rerankers — provider rerank model |
| delegated_runtime_id | DELEGATED_RUNTIME_ID | None | Delegated runtimes — managed agent id / runtime ARN / engine resource |
| delegated_runtime_environment | DELEGATED_RUNTIME_ENVIRONMENT | None | Delegated runtimes — environment / endpoint qualifier |
| otel_service_name | OTEL_SERVICE_NAME | 'e2a-service' | ManagedObservability — service.name resource attribute |
