# Requirements and user stories

| # | As a... | I want... | So that... | Acceptance |
|---|---|---|---|---|
| M1 | service developer | to choose a provider by configuration | the code does not change | a profile binds the provider's services to E2A's contracts |
| M2 | service developer | a Gemini Developer API profile | I can run a cloud landscape on a Gemini key | the `gemini_api` profile runs the landscape scenario |
| M3 | maintainer | CI without accounts or keys | contributions are safe | offline wire replay |
| M4 | operator | a retired model to fail in CI | production does not break on a date | the lifecycle test |
| M5 | architect | a record of which provider services replace, extend or leave to E2A | I can choose consciously | the design documents |

Out of scope: a hosted gateway, provider support.
